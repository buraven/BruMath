# BruMath 💚
Site mobile-first de finanças do casal.
## Publicação
Importe o repositório no Vercel. `npm install` e `npm run build`.
## Próxima etapa
A interface usa estado local para a primeira versão. Para sincronizar Bruna e Matheus em celulares diferentes, conecte Supabase e substitua o estado local por tabelas de despesas, categorias, limites e parcelas.
